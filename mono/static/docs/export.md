# Export

**ZIP to PDF/JSON.** Export loads a TAO QTI exam archive, lets you configure how
questions and answers are displayed, and produces a clean printable document or
a structured JSON export.

## Preparing the file in TAO

1. In **TAO**, select the exam or folder you want to export and click **Export**.
2. Choose the export type **QTI Exam 2.2** and click **Export**.
3. Download the generated `.zip`. If the download does not start immediately,
   wait for TAO to finish processing the task, then click the save icon.

## Using Export

1. **Browse** for the `.zip` from the previous step (or drop it in). The
   questions are parsed and rendered on the right automatically.
2. **Configure the view** with the available options:

   | Option | Description |
   |--------|-------------|
   | **Answer** | Show or hide answers |
   | **Instruction** | Show or hide instructions |
   | **Letter** | Bullet list or alphabetical list |
   | **Compare** | Visual comparison of two exams |
   | **Inzage** | Review mode — underlined answers |
   | **Sort question** | Sort questions by title |
   | **Randomize** | Shuffle questions / answers |
   | **Zoom** | Change the displayed element size |
   | **Multiple files** | Load and merge several exams |
   | **Show / hide** | Hide individual questions or reorder them |

3. **Export JSON** to get a structured data file, or **Get PDF** to open the
   print window and save / print the formatted result.

## Privacy

Export runs entirely in your browser. No file is uploaded or stored — all
parsing and rendering happens client-side.
