# Slides

**A guided tour of TAO.** The Slides presentation is a self-contained pitch
deck for TAO: the problem it solves, who it's for, how the modules fit
together, and why it's built the way it is.

## What it is

A keyboard- and touch-navigable deck covering the cover slide, the problem
statement, the vision, the target audience, the module overview, the exam
workflow journey, how the pipeline works end to end, the toolkit's strengths,
and a closing slide.

## Using Slides

1. Open [`/slides`](/slides) to start the deck from the cover slide.
2. Move between slides with the on-screen arrows, the **Left**/**Right**
   arrow keys, or by swiping on touch devices.
3. The progress dots and slide counter show where you are in the deck.
4. Use it as-is for a walkthrough, or as a reference when explaining TAO to
   someone new to the toolkit.

## Notes

- The deck is fully client-side, like the rest of TAO — nothing is uploaded
  or tracked.
- Animations respect `prefers-reduced-motion`.
