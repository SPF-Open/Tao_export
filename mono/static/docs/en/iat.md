# IAT

**Item analysis.** The Interactive Assessment Tool reviews the statistical
quality of exam items after a session: difficulty, discrimination and
per-alternative behaviour.

## What it does

IAT reads exam result data and surfaces, for each item, the metrics psychometric
review relies on — how hard a question was, how well it separates strong from
weak candidates, and how each answer alternative performed.

## Using IAT

1. **Load your data** from the header controls.
2. Review the **summary** for the overall picture of the session.
3. Inspect the **per-item table** for difficulty, discrimination and alternative
   statistics, sortable for quick triage.
4. Use the browser's print/PDF to keep a copy — the layout is print-friendly.

## Reading the metrics

- **Difficulty** — the proportion of candidates who answered correctly.
- **Discrimination** — how well the item distinguishes higher- from
  lower-scoring candidates.
- **Alternatives** — how often each option was chosen, to spot weak distractors
  or miskeyed answers.
