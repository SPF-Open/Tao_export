# Export

**ZIP vers PDF/JSON.** Export charge une archive d'examen TAO QTI, vous permet de configurer l'affichage des questions et des réponses, et produit un document imprimable propre ou un export JSON structuré.

## Préparer le fichier dans TAO

1. Dans **TAO**, sélectionnez l'examen ou le dossier à exporter et cliquez sur **Export**.
2. Choisissez le type d'export **QTI Exam 2.2** et cliquez sur **Export**.
3. Téléchargez le `.zip` généré. Si le téléchargement ne démarre pas immédiatement,
   attendez que TAO finisse de traiter la tâche, puis cliquez sur l'icône de sauvegarde.

## Utiliser Export

1. **Parcourez** pour trouver le `.zip` de l'étape précédente (ou déposez-le). Les
   questions sont analysées et affichées à droite automatiquement.
2. **Configurez la vue** avec les options disponibles :

   | Option | Description |
   |--------|-------------|
   | **Answer** | Afficher ou masquer les réponses |
   | **Instruction** | Afficher ou masquer les instructions |
   | **Letter** | Liste à puces ou liste alphabétique |
   | **Compare** | Comparaison visuelle de deux examens |
   | **Inzage** | Mode révision — réponses soulignées |
   | **Sort question** | Trier les questions par titre |
   | **Randomize** | Mélanger les questions / réponses |
   | **Zoom** | Modifier la taille des éléments affichés |
   | **Multiple files** | Charger et fusionner plusieurs examens |
   | **Show / hide** | Masquer des questions individuelles ou les réorganiser |

3. **Export JSON** pour obtenir un fichier de données structuré, ou **Get PDF** pour ouvrir
   la fenêtre d'impression et enregistrer / imprimer le résultat mis en forme.

## Confidentialité

Export fonctionne entièrement dans votre navigateur. Aucun fichier n'est téléversé ou stocké — toute
l'analyse et le rendu s'effectuent côté client.
